개인정보처리방침

시행일 2026년 10월 31일

my_study(이하 "사이트")는 이용자의 개인정보를 소중히 여기고, 꼭 필요한 정보만 다뤄요. 이 방침은 사이트가 어떤 정보를 어디에 저장하고 어떻게 쓰는지 설명해요.

1. 회원가입과 수집하는 개인정보

사이트는 회원가입이 없고, 이름, 전화번호, 이메일 같은 개인정보를 입력받지 않아요.

2. 이용자의 브라우저에 저장되는 정보

아래 정보는 이용자의 기기 브라우저(로컬 저장소)에만 저장되고 사이트 운영자에게 보내지지 않아요.

  • 단어 시험지: 입력한 단어 목록, 시험 제목, 학원 이름, 화면 설정
  • 오답노트: 보관함에 담은 문제 사진과 시험 이름
  • 깨끗한 시험지: 마지막에 입력한 학교, 학년, 과목 같은 시험 정보
  • 글자 읽기 서버 설정과 사용량 확인용 기기 번호(무작위로 만든 문자열)

브라우저 설정에서 이 사이트의 데이터를 지우면 모두 삭제돼요.

3. 서버로 보내지는 정보

사진 속 글자 읽기

단어 시험지와 오답노트에서 서버 글자 읽기를 쓰면, 고른 사진과 기기 번호가 사이트 운영자의 글자 읽기 서버로 보내져요. 사진은 글자와 문제 번호를 읽는 데만 쓰이고, 기기 번호는 한 기기가 너무 많이 쓰지 않도록 사용량을 세는 데만 쓰여요.

깨끗한 시험지 보관

깨끗한 시험지에서 완성하기를 누르면 올린 원본 사진, 필기를 지운 사진, 입력한 시험 정보(학교, 학년, 과목, 연도, 시험, 메모)가 기출문제 보관을 위해 서버에 저장돼요. 저장된 자료는 관리자 비밀번호를 아는 운영자만 볼 수 있고 외부에 공개하지 않아요. 시험지에 이름이나 학번이 적혀 있다면 지우고 올려 주세요.

저장된 자료의 삭제를 원하면 문의로 알려 주세요. 확인 후 지체 없이 삭제해요.

접속 기록

서버와 사이트 호스팅 업체는 보안과 오류 확인을 위해 IP 주소, 접속 시각, 브라우저 종류 같은 접속 기록을 자동으로 남길 수 있어요.

4. 외부 서비스

사이트는 아래 외부 서비스를 이용하며, 이 과정에서 이용자의 IP 주소 같은 기술 정보가 해당 업체에 전달될 수 있어요.

GitHub Pages사이트 호스팅
Google Fonts글꼴 제공
jsDelivr, cdnjs글자 인식, PDF, 엑셀, 사진 변환 프로그램 제공
브라우저 음성 인식단어 시험지의 말하기 기능. 브라우저에 따라 음성이 브라우저 제조사(예: Google, Apple)의 서버에서 처리될 수 있어요.

5. 광고와 쿠키

사이트는 운영 비용을 마련하기 위해 Google 애드센스 같은 광고를 게재할 수 있어요. 광고가 표시될 때는 다음 내용이 적용돼요.

  • Google을 비롯한 제3자 광고 업체는 쿠키를 사용해 이용자가 이 사이트나 다른 사이트를 방문한 기록을 바탕으로 광고를 보여 줄 수 있어요.
  • Google은 광고 쿠키를 사용해 이용자의 방문 기록에 맞는 광고를 제공해요.
  • 이용자는 Google 내 광고 센터에서 맞춤 광고를 끌 수 있고, www.aboutads.info에서 다른 광고 업체의 맞춤 광고 쿠키도 끌 수 있어요.
  • Google이 정보를 사용하는 방식은 Google 파트너 사이트 정보 사용 안내에서 볼 수 있어요.

브라우저 설정에서 쿠키 저장을 거부할 수 있지만, 일부 기능이 제대로 동작하지 않을 수 있어요.

6. 만 14세 미만 이용자

사이트는 회원가입 없이 쓸 수 있고, 아동의 개인정보를 일부러 수집하지 않아요. 보호자는 아이가 시험지 사진에 이름 같은 개인정보가 남지 않게 지도해 주세요.

7. 문의

개인정보와 관련한 문의, 열람이나 삭제 요청은 문의로 보내 주세요.

8. 방침 변경

이 방침이 바뀌면 이 페이지에 바뀐 내용과 시행일을 알려요.
