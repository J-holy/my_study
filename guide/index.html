1. 영어 단어 시험지 만들기

교재의 단어와 뜻을 읽어 들여 영어를 보고 뜻을 쓰는 시험, 뜻을 보고 영어를 쓰는 시험, 보기 중에서 고르는 시험을 만들어요.

단어 넣기

  • 직접 입력: 한 줄에 단어 하나씩 apple 사과처럼 적어요. 단어와 뜻 사이는 띄어쓰기, -, :, = 중 무엇으로 나눠도 되고, 엑셀에서 두 열을 복사해 붙여넣어도 돼요.
  • 파일에서 불러오기: 교재 사진, PDF, 엑셀 파일을 고르면 단어와 뜻을 읽어 와요. PDF는 읽을 쪽을 고를 수 있어요.
  • 칸 그려서 읽기: 단어와 뜻이 두 칸으로 나뉜 교재라면 단어 칸과 뜻 칸을 손가락으로 그려 주면 더 정확하게 읽어요.

읽어 온 단어는 불러온 단어 확인에서 틀린 글자를 고친 다음 입력창에 추가해요.

시험 설정과 출력

  • 문제 수(10, 20, 30, 50, 100개), 문제 방식(영어 보고 뜻 쓰기, 뜻 보고 영어 쓰기, 객관식), 순서 섞기를 고르고 시험지 만들기를 눌러요.
  • 시험지 인쇄와 답안지 인쇄로 종이 시험지를 만들어요.
  • 학생용 링크 만들기로 학생이 휴대폰에서 바로 풀 수 있는 온라인 시험을 보낼 수 있어요. 다 풀면 점수와 틀린 단어가 나오고, 틀린 문제만 다시 풀 수 있어요.

단어 시험지 열기

2. 오답노트 만들기

채점한 시험지 사진에서 틀린 문제만 오려 내 필기를 지우고, 한 권의 오답노트 PDF로 묶어요.

  1. 사진 올리기: 시험지 사진을 여러 장 한꺼번에 올려요. 처음이라면 예시 사진으로 체험을 눌러 보세요.
  2. 사진 보정: 기울기와 밝기를 맞춰요.
  3. 필기 지우기: 빨간 펜, 파란 펜 같은 색깔 필기는 자동으로 지워져요. 남은 자국은 지우개로 문질러 지워요.
  4. 틀린 문제 고르기: 문제 사이를 나누는 간격을 조절하거나, 문제 번호로 나누기를 눌러 문제 칸을 나눈 다음 틀린 문제만 골라요.
  5. 보관함: 고른 문제는 시험별로 보관함에 쌓여요.
  6. PDF 출력: 문제 아래에 풀이 공간(빈칸, 줄, 모눈)을 넣어 PDF로 저장하거나 인쇄해요.

오답노트 열기

3. 깨끗한 시험지 만들기

이미 푼 시험지를 다시 풀 수 있게, 필기와 채점 자국을 지우고 문제만 남겨요.

  1. 시험지 사진을 올리고 문서처럼 펴기로 비스듬히 찍힌 사진을 반듯하게 펴요.
  2. 필기 지우기를 누르면 색깔 필기와 연필 자국이 지워져요. 검은 펜 자국은 지우개로 지우고, 잘못 지운 곳은 되살리기로 살려요.
  3. 학교, 학년, 과목, 연도, 시험 정보를 적고 완성하기를 누르면 PDF로 저장하거나 인쇄할 수 있어요.

완성한 시험지는 기출문제 보관용으로 서버에 저장되고, 관리자만 볼 수 있어요. 이름 같은 개인 정보는 적지 말아 주세요.

4. 사진을 잘 찍는 방법

  • 종이 전체가 화면에 들어오게, 위에서 똑바로 내려다보며 찍어요.
  • 그림자가 지지 않게 밝은 곳에서 찍고, 플래시 반사가 생기면 끄세요.
  • 글자가 흐리면 조금 더 가까이 가서 한 쪽씩 찍는 편이 잘 읽혀요.
  • 아이폰의 HEIC 사진도 그대로 올릴 수 있어요.

5. 자주 묻는 질문

돈을 내야 하나요?

아니요. 모든 도구는 무료이고 회원가입도 필요 없어요.

만든 단어 목록은 어디에 저장되나요?

지금 쓰는 브라우저에 저장돼요. 다른 기기에서 이어서 쓰려면 단어 목록을 복사해 옮기거나 파일로 받아 두세요. 브라우저의 방문 기록과 사이트 데이터를 지우면 함께 지워져요.

글자가 잘못 읽혀요.

사진을 더 밝고 반듯하게 다시 찍거나, 단어 칸과 뜻 칸을 직접 그려서 읽어 보세요. 그래도 안 되면 문의로 알려 주시면 고쳐 볼게요.

휴대폰에서도 되나요?

네. 휴대폰, 태블릿, 컴퓨터의 최신 브라우저(크롬, 사파리, 엣지, 삼성 인터넷)에서 쓸 수 있어요.

인쇄가 잘리거나 작게 나와요.

인쇄 창에서 용지를 A4로, 배율을 기본값 또는 100%로 맞추고, 머리글과 바닥글을 끄면 깔끔하게 나와요.
